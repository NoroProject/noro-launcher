# Управление игровыми серверами через ServerWrapper

Подсистема, которая даёт админке власть над машинами игровых серверов: моды,
файлы и конфиги, консоль, питание, бэкапы. Плюс переписанный каталог модов, из
которого мод ставится сразу и в клиентскую сборку, и на выбранные сервера.

Работа разбита на фазы; после каждой лежит файл с контекстом — чтобы работу мог
подхватить кто угодно, не читая всю историю.

## Архитектура в двух абзацах

Враппер живёт на машине игрового сервера и **сам приходит** к мастеру по
WebSocket — обратного пути нет и не нужно. Авторизация — тем же секретом
игрового сервера, что и у агента (`AgentAuth`). На мастере реестр подключений
`WrapperHub`; админский HTTP превращается в команду в сокет и ожидание ответа с
таймаутом.

Враппер из одноразового установщика стал демоном: соединение живёт независимо от
процесса сервера, поэтому мод можно поставить и перезапустить сервер, а на
упавшем сервере панель не мертва.

## Границы

Запись файла в серверную директорию плюс рестарт — это по сути рут на игровой
машине. Поэтому всё, что идёт через враппер, закрыто отдельным правом
`noro.admin.wrapper`, а не общим `noro.admin.servers`.

Файловые операции ограничены серверной директорией: `..` и симлинки наружу
отбиваются, конфиг враппера (в нём plaintext-секрет) не читается и не пишется.
