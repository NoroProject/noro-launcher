# Screenshots

Images referenced by the main README. Names must match:

| File | Shows |
|---|---|
| `main.png` | Main screen with a server selected |
| `sync.png` | Files downloading before launch |
| `mods.png` | Optional mods catalogue |
| `profile.png` | Profile page with the skin preview |
| `settings.png` | Settings screen |

Keep them at the launcher's normal window size, and avoid capturing a real
username where it isn't needed.
