- State truthfully that your project **is based on**, **is a fork of**, or **is
  compatible with** Noro
- Use the name to refer to this project — in articles, tutorials, comparisons,
  bug reports, academic work
- Link to the official repository and website
- Run an unmodified Noro master for your own network and call it what it is

This is nominative use: naming something to talk about it is always allowed, and
nothing here is meant to restrict criticism, comparison or discussion.

## What requires permission

- Naming your fork or derivative "Noro", "NoroLauncher", or any name likely to

- Publishing a modified launcher build under the Noro name
- Implying endorsement, affiliation or official status

## If you fork

You are welcome to. The licence guarantees that right, and forks are a normal
part of free software. Two obligations come with it:

1. **Rename it.** Pick a name that is clearly not Noro, and replace the logo and
   icons. Users must be able to tell whose software they are running.
2. **Keep the source open.** AGPL-3.0 section 13 applies: if you run a modified
   master and users interact with it over a network, you must offer them the
   complete corresponding source of your version.

Retaining the original copyright and licence notices is required by the AGPL
itself, independently of this policy.

Before you fork, consider opening a pull request instead. Changes that live
upstream get reviewed, maintained and released; changes that live in a fork
become yours to rebase forever.
